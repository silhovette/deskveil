`face_landmarker.task` is the Google MediaPipe Face Landmarker float16 v1 model bundle.

Source: https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

Documentation / model cards: https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker

Included for offline inference. `tools/download_model.py` can retrieve a missing copy during installation. The runtime does not download models.
